# SwiftPull — releases

Installers and update notices for SwiftPull (formerly "Download Manager"), by Mostafa Kotb.
The apps check this repository for new versions; there is no source code here.

## Windows

Get `SwiftPull-Setup.exe` from the newest release whose name starts with **SwiftPull for Windows**
on the [Releases](../../releases) page.

## Android

Get the newest release whose name starts with **SwiftPull for Android** on the
[Releases](../../releases) page.

- Phones and tablets: `SwiftPull-x.y.z.apk`
- Chromebooks with an Intel or AMD processor: `SwiftPull-x.y.z-Chromebook.apk`

Android asks for permission to install apps from outside the Play Store the first time.

## Updates

Once installed, both apps update themselves: on Windows from Help → Check for updates, on
Android from Settings → Updates. Windows update notices are signed, and the app only accepts
ones signed by the publisher.
