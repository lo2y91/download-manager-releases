# Download Manager — releases

Installers and update notices for Download Manager. The apps check this repository for new
versions; there is no source code here.

## Android

Get the latest `DownloadManager-x.y.z.apk` from [Releases](../../releases/latest).

- Phones and tablets: `DownloadManager-x.y.z.apk`
- Chromebooks with an Intel or AMD processor: `DownloadManager-x.y.z-Chromebook.apk`

Once installed, the app updates itself: Settings → Updates.

Android asks for permission to install apps from outside the Play Store the first time.
